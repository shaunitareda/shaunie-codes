# shaunie.codes

Minimal developer portfolio for **Shaunie** (`@shaunitareda`).

The site is intentionally repository-first: a short introduction, a small set of selected projects, and direct links to the underlying GitHub repositories.

## Current featured work

- **Bill on the Floor** — civic-tech bot for U.S. House and Senate floor activity
- **Downloads Cleaner** — local-first Windows Downloads organizer
- **Crossposting tools** — WordPress integrations for open social platforms

## Stack

Plain HTML and CSS. No framework, build step, analytics, tracking, or external JavaScript.

## Publishing

The repository is ready for static hosting. The intended public domain is `shaunie.codes`.
